# Third-party TTS components

Runtime license obligations for neural TTS models and adapters.

| Component | Code/runtime license | Model or weights license | Source |
|---|---|---|---|
| Pocket TTS | MIT | CC-BY-4.0 for the public no-voice-cloning weights. Individual preset recordings have source-specific licenses; see the voice attribution below. The model card prohibits deceptive or unauthorized voice impersonation. | [Kyutai repository](https://github.com/kyutai-labs/pocket-tts), [weights](https://huggingface.co/kyutai/pocket-tts-without-voice-cloning), [voice sources and licenses](https://huggingface.co/kyutai/tts-voices) |
| Piper | GPL-3.0-or-later for the current `piper-tts` runtime | Each voice model has its own model card and terms; the voice repository is not one blanket model license. | [runtime](https://github.com/OHF-Voice/piper1-gpl), [178-voice catalog](https://huggingface.co/rhasspy/piper-voices) |
| Supertonic 3 | MIT SDK | OpenRAIL-M | [SDK](https://github.com/supertone-oss-archive/supertonic-py), [model](https://huggingface.co/supertone-oss-archive/supertonic-3) |
| MOSS-TTS-Nano ONNX | Apache-2.0 | Apache-2.0 for both ONNX repositories | [runtime](https://github.com/OpenMOSS/MOSS-TTS-Nano), [TTS weights](https://huggingface.co/OpenMOSS-Team/MOSS-TTS-Nano-100M-ONNX), [audio tokenizer](https://huggingface.co/OpenMOSS-Team/MOSS-Audio-Tokenizer-Nano-ONNX) |
| Qwen3-TTS | Apache-2.0 | Apache-2.0 | [code](https://github.com/Qwen/Qwen3-TTS), [model](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice) |

Voice samples generated for the app use the canonical benchmark sentence. The upstream
licenses and source links above should remain with any redistribution of the corresponding
runtime or weights.

## Pocket TTS preset voice attribution

The catalog includes all 27 predefined voices exposed by the installed Pocket TTS 4.0.1
runtime: 21 English and one each for Italian, Spanish, German, Portuguese, Dutch, and French.
The public voice-source card assigns licenses by source dataset, not one blanket license to
every recording:

| Presets | Source and license |
|---|---|
| Alba | Alba MacKenna, CC-BY-4.0 |
| Marius, Javert | Voice donations, CC0 |
| Anna, Vera, Fantine, Charles, Paul, Eponine, Azelma, George, Mary, Jane, Michael, Eve | VCTK, CC-BY-4.0 |
| Bill Boerst, Peter Yearsley, Stuart Bell, Caro Davy | Voice-Zero, CC0 |
| Cosette | Expresso, CC-BY-NC-4.0; non-commercial only |
| Jean | EARS, CC-BY-NC-4.0; non-commercial only |
| Estelle | Unmute project recording, CC0 |
| Daan | CML-TTS, CC-BY-4.0 |
| Giovanni, Lola | Common Voice source clips; the upstream voice card does not restate the clip-level terms |
| Jürgen, Rafael | The upstream source entry does not state a license; the app marks these voices accordingly |

The Pocket TTS voice files are downloaded from Kyutai's no-voice-cloning repository and are
not bundled in the installer. The two non-commercial voices are explicitly marked in the
voice picker; Jürgen and Rafael are marked because their source entries do not state a license.
Do not treat the model weights' CC-BY-4.0 license as overriding the source license of a voice.
