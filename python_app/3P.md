# Third-party TTS components

Runtime license obligations for neural TTS models and adapters.

| Component | Code/runtime license | Model or weights license | Source |
|---|---|---|---|
| Pocket TTS | MIT | CC-BY-4.0 for the public no-voice-cloning weights. The model card prohibits deceptive or unauthorized voice impersonation. | [Kyutai repository](https://github.com/kyutai-labs/pocket-tts), [weights](https://huggingface.co/kyutai/pocket-tts-without-voice-cloning) |
| Supertonic 3 | MIT SDK | OpenRAIL-M | [SDK](https://github.com/supertone-oss-archive/supertonic-py), [model](https://huggingface.co/supertone-oss-archive/supertonic-3) |
| MOSS-TTS-Nano ONNX | Apache-2.0 | Apache-2.0 for both ONNX repositories | [runtime](https://github.com/OpenMOSS/MOSS-TTS-Nano), [TTS weights](https://huggingface.co/OpenMOSS-Team/MOSS-TTS-Nano-100M-ONNX), [audio tokenizer](https://huggingface.co/OpenMOSS-Team/MOSS-Audio-Tokenizer-Nano-ONNX) |
| Qwen3-TTS | Apache-2.0 | Apache-2.0 | [code](https://github.com/Qwen/Qwen3-TTS), [model](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice) |

Voice samples generated for the app use the canonical benchmark sentence. The upstream
licenses and source links above should remain with any redistribution of the corresponding
runtime or weights.
